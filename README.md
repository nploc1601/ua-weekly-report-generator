# UA Weekly Report Generator

Client-side UA reporting tool for Adjust/ad-network exports.

## What it does
- Upload multiple Adjust / ad-network CSV/XLSX files
- Auto-detect ad networks from campaign naming
- Analyze Game Health, Network Detail, cohort maturity and campaign KPI buckets
- Generate Finding → Evidence → Action
- Export a formatted XLSX weekly report

## Deployment
This repository is configured for GitHub Pages via GitHub Actions.
